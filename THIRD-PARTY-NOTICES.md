# Third-party notices

The released `main.js` bundles the following open-source software. Each library's license applies to its own code. License texts are available in the linked repositories and in the corresponding npm packages; this file lists what is bundled, and the minified `main.js` keeps only the license comments its bundler preserved.

## Directly bundled

- [pdfmake](https://github.com/bpampuch/pdfmake) 0.2.x, MIT License. Its prebuilt browser build is bundled as one file and contains the libraries listed below.
- [woff2-encoder](https://github.com/itskyedo/woff2-encoder) 2.x (WOFF2 decoder, WebAssembly build of Google's woff2 and brotli), MIT License
- Adobe core 14 font metrics (AFM files for Helvetica and Courier), distributed with pdfkit under Adobe's permissive AFM license

## Contained in pdfmake's browser build

- [pdfkit (foliojs fork)](https://github.com/foliojs/pdfkit), MIT License
- [fontkit (foliojs fork)](https://github.com/foliojs/fontkit), MIT License
