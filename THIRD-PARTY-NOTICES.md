# Third-party notices

The released `main.js` bundles the following open-source software. Each library's license applies to its own code. License texts are available in the linked repositories and in the corresponding npm packages; this file lists what is bundled, and the minified `main.js` keeps only the license comments its bundler preserved.

## Directly bundled

- [pdfmake](https://github.com/bpampuch/pdfmake) 0.2.x, MIT License. Its prebuilt browser build is bundled as one file and contains the libraries listed below.
- [woff2-encoder](https://github.com/itskyedo/woff2-encoder) 2.x (WOFF2 decoder, WebAssembly build of Google's woff2 and brotli), MIT License
- [MathJax](https://github.com/mathjax/MathJax-src) (`mathjax-full` 3.2.2, TeX input and SVG output with its bundled math fonts), Apache License 2.0
- [DejaVu Sans](https://dejavu-fonts.github.io/) 2.37, a subset (Greek letters, arrows, mathematical operators, super/subscripts and a few symbols; about 58 KB) embedded as the built-in last-resort fallback font for inline math. Bitstream Vera licence with public-domain DejaVu changes (see below)
- Adobe core 14 font metrics (AFM files for Helvetica, Times and Courier), distributed with pdfkit under Adobe's permissive AFM license

## Licence texts

Copied verbatim from each package's licence file in `node_modules` at build time. Where a package ships no licence file, the standard MIT text is given with the author named in its `package.json` (marked below). The entries for `buffer`, `ieee754`, `regenerator-runtime` and `string.fromcodepoint` are compiled into pdfmake's browser build but are not installed separately, so their licence files were taken from the published npm tarballs instead: `buffer` 6.0.3 is the version pdfmake declares (`^6.0.3`), and the other three are the latest published versions, as the bundle does not record theirs.
